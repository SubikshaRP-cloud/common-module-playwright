# Common Playwright - All Screens

Screens included from the recorded Common Module flow:
Country, Currency, Payment Modes, Delivery Modes, Trade Terms, Sales Type, Bank, Expense Type, Customer (page object can be added from the recorded flow), Supplier Group, Supplier, Purchase Currency Rate, Sales Currency Rate, Parameters, Parking and Location / Parking Slots.

Run:
```powershell
npm.cmd install
npx.cmd playwright install chromium
npx.cmd playwright test --headed
```

Login credentials are in tests/auth.setup.js as requested.

Codes generated by utils/testData.js are exactly 5 uppercase alphabetic characters.
